# Simple-Banking-System

## Description
This code will allow customers to deposit, withdrawal, check balance and track balance
## How to Run
1. Open the project folder in Xcode
2. Press Ctrl+F5 to build and run
3. There will be 4 choices on the screen: Deposit, Withdraw, Check Balance or Exit

## 
Input: Choice: 1. Deposit Money Amount: $250
Output: Deposit Successful New Balance: $1250
